PROYECTO 02

RIFT RAIDERS

Juego arcade de combate por oleadas ambientado en universos paralelos.

Sobre el proyecto

Rift Raiders es un juego arcade de acción desarrollado utilizando Unity y C#. El jugador debe enfrentarse a diferentes enemigos mientras avanza por escenarios inspirados en distintos universos.

El proyecto fue desarrollado como parte de mi proceso de formación en desarrollo de videojuegos, enfocándome principalmente en programación y sistemas de gameplay.

Durante el desarrollo trabajé en diferentes sistemas necesarios para crear un flujo completo de juego, desde el movimiento del jugador hasta los enemigos, oleadas y elementos de interfaz.

Tecnologías

Unity C# 2D Gameplay UI

¿Qué desarrollé?

🎮 Movimiento del jugador

Desarrollo del sistema de movimiento y control del personaje dentro del escenario.

👾 Sistema de enemigos

Implementación de enemigos con diferentes comportamientos dentro de las zonas de combate.

🌊 Sistema de oleadas

Creación del sistema encargado de controlar la aparición progresiva de enemigos.

♻️ Spawner

Desarrollo del sistema encargado de generar enemigos durante las diferentes oleadas.

👑 Sistema de jefe

Implementación de un jefe y elementos de interfaz relacionados con su sistema de vida.

❤️ Sistema de vida

Sistema encargado de gestionar la vida del jugador y los enemigos.

📊 HUD

Desarrollo de elementos de interfaz para mostrar información relevante durante la partida.

🎥 Cámara

Configuración y programación del seguimiento de cámara durante el gameplay.

PROYECTO 06

AUGMENTED
REALITY

Proyecto de Realidad Aumentada desarrollado para integrar elementos 3D dentro de un entorno real utilizando la cámara de un dispositivo.

Demo

Sobre el proyecto

Este proyecto fue desarrollado para explorar el uso de la Realidad Aumentada aplicada al desarrollo de experiencias interactivas.

La aplicación utiliza la cámara del dispositivo para mostrar elementos virtuales integrados dentro del entorno físico.

Durante la experiencia es posible visualizar diferentes modelos 3D posicionados dentro del espacio real, permitiendo observar cómo los elementos virtuales interactúan visualmente con el entorno.

El proyecto permitió trabajar conceptos relacionados con Realidad Aumentada, posicionamiento de objetos 3D, cámara, interacción y desarrollo para dispositivos.

Tecnologías

Unity C# AR 3D Mobile

Características

Realidad Aumentada

Integración de elementos virtuales dentro de un entorno físico utilizando la cámara del dispositivo.

Objetos 3D

Visualización de diferentes modelos tridimensionales dentro del espacio real.

Cámara

Uso de la cámara del dispositivo como parte fundamental de la experiencia.

Interacción

Experiencia interactiva basada en la visualización y posicionamiento de elementos virtuales.

Entorno Real

Los objetos virtuales son integrados visualmente dentro de espacios físicos.

Experiencia Mobile

Proyecto pensado para ejecutarse utilizando un dispositivo móvil.
